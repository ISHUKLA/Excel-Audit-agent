# Expected Results

This directory will contain the expected audit outputs for each demonstration case.

## Structure

- `case_1_expected_findings.json` — Expected anomalies (none)
- `case_1_expected_reconciliation.json` — Expected internal/external verdicts
- `case_2_expected_findings.json` — Expected blocker and warning findings
- `case_2_expected_reconciliation.json` — Expected incomplete verdict
- `case_3_expected_findings.json` — Expected anomalies (none)
- `case_3_expected_reconciliation.json` — Expected block on external verdict

Each file documents the expected audit trail for judges running the demonstration.
